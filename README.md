# HD2LobbyBrowser
大厅搜索器：不再随机匹配，自己挑房间进！EAC 更新后依然可用
官方只能随机匹配，进去才发现任务不对、队友全在国外。
这个工具把所有公开大厅列出来，任务、地区、延迟、SOS 全写在表里，你自己挑。

■ 这次更新（重点）
· 任务筛选上线：按游戏真实任务名挑房 —— 闪电战 / 取回 / 勘探 / 发射洲际弹道导弹…
面板里多选、可搜索、可全选，任务再多也不挤
· 任务名不再是编号：直接读游戏任务数据里的 mission_hash，对应 126 个任务名
· 难度改成读游戏数据：勾 10 级就是 10 级，不再出现「点 10 级进去是别的难度」
· 界面整体提亮，战线选中态改成实心 + 勾号，一眼看出选了什么

■ 基础功能
· 一次扫 6–9 个活跃星球，列出两三百个公开大厅
· 战线（虫族/机器人/光能族）/ 地区 / 平台 / 星球 / 难度 多条件筛选
· 星球三级联动：战线 → 星系 → 星球，后两级带实时玩家人数
· 星球名、星系名官方简中（273 + 56），中英可切
· 实时延迟：测你到该房间所在区域 Steam 中继的延迟（亚洲 48ms / 欧美 168ms）
· SOS 标记：哪些房在等人，一眼看出来
· 点表头排序：星球 / 战线 / 难度 / 人数 / 任务 / 延迟 / 地区 / 建立时间
· 独立窗口 + 全局热键 Ctrl+Alt+H，全屏也能唤起
· 单文件 exe，13MB，免安装、免 Python、免浏览器

■ 用法
1. 双击 HD2LobbyBrowser.exe
2. 勾战线和地区，点刷新，等 4-5 秒
3. 想打特定任务就点右上角「任务」挑几项
4. 看中哪个点「加入」

■ 安全（不是 mod，不需要任何前置）
不读游戏内存、不注入、不改文件；独立进程读 Steam 公共大厅列表，加入走官方 joinlobby。
机制上不会触发 EAC —— 这也是 7.2.0 上 EAC 后它还能用的原因。第三方工具风险请自行判断。

■ 已知限制
· 「延迟」是到该房间所在区域 Steam 中继的实测值，不是房主本人延迟（跨平台会话不公开房主身份）
· 任务名靠本地 126 条任务表，游戏刚加的新任务会显示「未识别任务」
· 刷新到加入之间房主可能换任务，所以刷完请等 4-5 秒、尽快点
· 需 Steam 在线；需 Edge WebView2 运行时（Win11 自带）
