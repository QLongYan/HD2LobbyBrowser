HD2 大厅搜索器 V30 —— 独立窗口版
================================================

双击 HD2LobbyBrowser.exe 就能用。
不用装 mod、不用开浏览器、不用先开游戏（点「加入」时游戏要开着）。


一、启动与快捷键
------------------------------------------------
· 双击后约 4 秒弹出独立窗口，标题下显示当前版本
· Ctrl + Alt + H：唤起 / 收起窗口，全屏游戏里也能用
  （游戏请用「无边框全屏」；独占全屏下 Windows 不允许其他窗口盖上去）
· 有新版本时版本号旁会出现提示，点「升级」即可


二、界面
------------------------------------------------
顶部按钮：变种类型 / 地图类型 / 任务 / 全部星球 / 难度
下面一行：战线、地区、平台，以及各种筛选开关
表格列：星球、战线、难度、人数、任务、平台、隐私、延迟、地区、房主、SOS、建立、加入


三、搜索与筛选
------------------------------------------------
【刷新】
按当前条件重新搜，一次扫 12 个活跃星球，通常 300–900 个房。

【战线 / 地区 / 平台】
点一下选中，再点一下取消；可以多选。

【全部星球】
· 分区和星球都可以勾选
· 勾一个分区 = 这个分区下所有星球自动勾上
· 也可以单独取消 / 勾选某颗星球（分区框会显示半选）
· 底部显示已选数量，点「应用」生效；不勾 = 全部星球

【难度】
· 可多选：未选任务 + 1–10 级
· 勾好后点「应用」生效；不勾 = 全部难度

【任务】
点「任务」打开面板：可多选、可搜索、可全选/清空，只筛当前结果。

【地图类型】
野外 / 殖民地 / 城市 / 虫窝世界 / 巨型工厂，可多选。
一个房有多个类型时显示「野外/殖民地」，勾其中任一个都会保留。

【变种类型】
掠食、孢裂、裂地、喷气旅、灼烧旅、蟑龙、霸王虫等，共 20 类。
· 变种是星球级的，同一星球的所有房显示同一组
· 一个星球有多个变种时显示「霸王虫/蟑龙」，勾任一个都会保留
· 面板里的 0 表示当前结果里没有这个变种

【开关】
只看公开房 / 隐藏满员 / 隐藏无会话房 / 隐藏进不去的房 / 只看 SOS 房 / 私服
「私服」= 只留 Steam 直连（跨平台关）的房。

【已进入的房间】
加入后整行金色高亮并排在最上面，刷新也不会消失。


四、表格说明
------------------------------------------------
· 星球：第二行是「星系 · 地图类型 · 变种」
· 延迟：本机到该房所在区域的中继延迟，不是到房主
· 平台 / 房主：表格出来后约 5 秒自动补全
· 人数：每 3 分钟刷新；接口慢时先显示上次缓存的数据
· 难度带 *：房间还没发布任务数据，按房间信息推测
· 任务「未识别」：游戏新增了任务，等软件更新
· 已进入的房：按钮显示「你在这里」


五、加入房间
------------------------------------------------
· 刷新后等 4–5 秒再点「加入」，避免进错房
· 加入没反应，常见原因：房主设了好友可见、房间已关闭、你正在任务中
· 12 秒没进去会提示，并把这个房标记为「进不去」，下次刷新隐藏


六、保存预设与升级
------------------------------------------------
· 保存预设：记住当前所有筛选和排序，下次启动自动套用并直接搜索
  想恢复默认：删掉同目录的 preset.json
· 升级：自动检查 GitHub，有新版本时点「升级」，页面底部显示下载进度
  下载失败可以稍后重试，或到 GitHub Releases 手动下载


七、常见问题
------------------------------------------------
【杀软报高风险】
单文件 exe、没有数字签名，容易被启发式误报，不是病毒。
不放心可以自己编译，源码在 GitHub；日常用选「仍要运行」或加排除目录。

【更新后打不开 / 提示 python311.dll 找不到】
多是杀软在更新后第一次启动时拦住了临时解压：关掉提示，重新双击一次通常就好；
仍然报错就把软件目录和 %TEMP% 加进杀软排除，或手动下载 exe 覆盖。

【中国服】
游戏没有中国服，地区里没有这一项。

【与房主的延迟】
游戏外的程序拿不到房主延迟，表里的「延迟」是中继延迟，只能作参考。

【同一时间房间数忽多忽少】
软件只扫每条战线前几个活跃星球，星球热度、公开房比例、单星球 50 条上限、
Steam 列表刷新延迟都会影响；总人数没大变，不代表这些星球的房数不变。

【毒瘴 / 腐蚀变种】
游戏里有毒瘴变种、腐蚀变种，但它们是虫族全局变种，接口没有按星球/房间标记，
所以暂时筛不到，不是漏做。


八、文件说明
------------------------------------------------
· preset.json：保存的预设
· join_fail.json / hotkey.log：运行日志，删掉不影响使用
· 换电脑：整个文件夹复制过去即可
