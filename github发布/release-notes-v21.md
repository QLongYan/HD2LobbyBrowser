# HD2 大厅搜索器 V21

## 本次更新

**自动更新改走 GitHub，启动就告诉你有没有新版。**

- 升级源从 A网 换成 GitHub Release，不再受「要登录才能下载」的限制
- 每次启动后台检查一次最新版，不拖慢窗口
  - 有新版本 → 标题旁金色「有新版 V22」，「升级」按钮点亮（呼吸光）
  - 已是最新 → 显示「已是最新版」，按钮置灰
  - 网络不通 → 显示「检查更新失败」，按钮仍可手动点
- 点「升级」自动下载、校验、替换并重启；失败会提示去 B站 / A网 下载
- 国内直连 GitHub 失败时，自动尝试 `ghproxy.net` / `gh-proxy.com` 镜像
- 修复 V20 的一个问题：窗口版实际没有触发版本检查，所以「有新版本」提示从没出现过

## 下载

下载本页下方的 **HD2LobbyBrowser.exe**（约 13 MB），双击运行即可。

- 需要 Steam 客户端已启动并登录
- 免安装、免前置、不注入游戏、不碰 EAC
- 首次运行若被 SmartScreen 拦，点「更多信息 → 仍要运行」

## 已有功能

任务筛选（126 条任务名，来自游戏数据包）· 星球三级联动 · 地区与延迟 · PC / PS / Xbox 平台
· SOS · 房主名 · 十列排序 · 保存预设（下次启动自动套用）· `Ctrl+Alt+H` 全局唤起

## 已知限制

- 任务是刷新那一刻的快照，从刷新到点「加入」之间房主可能换任务
- 平台与房主名要联网查一次 PlayFab，首次刷新会慢 2–6 秒，之后走缓存
- 房主等级无法获取（只在游戏进程内存里，外部读不到，本工具不注入）
