# HD2LobbyBrowser
官方只能随机匹配：看不到任务、看不到地区、看不到房主是什么平台，
进去才发现队友全在国外，或者根本不是你想打的那个任务。
这个工具把「所有公开大厅」列出来，你自己挑。

━━━━━━━━━━━━━━━━━━━━━━
■ 这次更新了什么
━━━━━━━━━━━━━━━━━━━━━━

· 升级会自动换数据
  以前更新只换主程序，任务表还是旧的，游戏一加新任务就对不上。
  现在点「升级」下的是整包：主程序 + 任务表 + 星球名一起换，点完自动重启。

· 平台列上线
  房主用的是 PC、PS 还是 Xbox，直接标在表里。
  数据来自游戏自己发布的公开资料（和游戏内显示平台图标同源），
  不读内存、不注入；也能在顶部按平台筛，只想进 PC 房就勾 PC。

· 任务筛选常驻
  按任务名挑房：闪电战 / 取回 / 勘探 / 发射洲际弹道导弹 / 破坏空军基地……
  面板里多选、能搜索、能全选，任务再多也不挤。

· 保存预设
  勾好的战线、地区、平台、任务、难度、开关全部存下来，
  下次开软件自动套用并直接开始搜，不用再点一遍。

━━━━━━━━━━━━━━━━━━━━━━
■ 能做什么
━━━━━━━━━━━━━━━━━━━━━━

· 一次扫 6–9 个活跃星球，列出两三百个公开大厅
· 按 战线（虫族/机器人/光能族）、地区、平台、星球、难度、任务 筛选
· 星球选择三级联动：战线 → 星系 → 星球，每个星系和星球后面都标着当前玩家人数
· 星球名、星系名全部中文（官方简中，273 个星球 + 56 个星区），中英一键切换
· 实时延迟：直接测你到该房间所在区域 Steam 中继的延迟，亚洲 48ms / 欧美 168ms
· SOS 标记：红标显示哪些房间在呼叫 SOS，缺人的房一眼看出来
· 表头点一下排序：星球 / 战线 / 难度 / 人数 / 任务 / 平台 / 延迟 / 地区 / 房主 / 建立时间
· 可一键隐藏「无会话」房（组队但还没开任务，点进去必失败）；默认只勾「只看公开房」
· 独立窗口 + 全局热键 Ctrl+Alt+H，全屏游戏里也能直接唤起
· 单文件 exe，13 MB，免安装、免 Python、免浏览器

━━━━━━━━━━━━━━━━━━━━━━
■ 怎么用（四步）
━━━━━━━━━━━━━━━━━━━━━━

1. 双击 HD2LobbyBrowser.exe
2. 勾选你要的战线和地区，点刷新
3. 想打特定任务就点右上角「任务」，勾几项（可搜索，输入「闪电」就只剩闪电战）
4. 等 4–5 秒，看中哪个房间点「加入」

━━━━━━━━━━━━━━━━━━━━━━
■ 任务名和平台是怎么来的
━━━━━━━━━━━━━━━━━━━━━━

Steam 大厅里没有任务名字段，但有一个任务数据包（十六进制串），
里面写着阵营、难度和 mission_hash。程序按固定位置取出 hash，
再用 `mission_names.json`（126 条 hash → 中文任务名）翻译。
表里没有的新任务会显示「未识别任务」，悬停能看到 hash。

平台来自游戏发布的 PlayFab 公开资料里的 `testament_backing_platform`
（0=PS / 1=Steam / 4=Xbox），和游戏内显示平台图标是同一份数据。
程序用本机 Steam 票据做一次只读查询，不接触游戏进程。

━━━━━━━━━━━━━━━━━━━━━━
■ 关于自动更新
━━━━━━━━━━━━━━━━━━━━━━

每次开软件会在后台问一次「有没有新版」：
· 有新版本 → 标题旁显示金色提示，「升级」按钮点亮，你自己决定升不升
· 已是最新 → 显示「已是最新版」，按钮灰着
· 网络不通 → 显示「检查更新失败」，不影响使用，可以手动点重试

点「升级」后下载整包、校验、替换、自动重启；
你保存的预设和日志不会被覆盖。下载失败会提示去 B站 / A网 / GitHub 手动下。

━━━━━━━━━━━━━━━━━━━━━━
■ 为什么刷新完要等 4–5 秒
━━━━━━━━━━━━━━━━━━━━━━

Steam 和箭头服务器之间有几秒同步延迟。刚刷完的列表可能还是几秒前的状态，
这时候点「加入」容易进错房（显示的任务/难度已经不是最新的）。
界面上专门有一条提示条写这件事，照做就行。

━━━━━━━━━━━━━━━━━━━━━━
■ 安全性说明
━━━━━━━━━━━━━━━━━━━━━━

· 全程不读游戏内存、不注入、不改游戏文件
· 原理：在独立进程里读 Steam 的公共大厅列表，加入走 Steam 官方的 joinlobby
· 从机制上讲不会触发 EAC —— 这也是 7.2.0 上 EAC 之后它还能用的原因
· 但任何第三方工具都存在风险，用不用请自行判断

━━━━━━━━━━━━━━━━━━━━━━
■ 已知限制（先说清楚）
━━━━━━━━━━━━━━━━━━━━━━

· 「延迟」是到该房间所在区域 Steam 中继的实测值，不是到房主本人的延迟
· 任务名靠本地 126 条任务表：游戏新加的任务会显示「未识别任务」，等下次更新补上
· 任务筛选只列「当前结果里出现过的任务」，换星球/难度重扫后列表会更新
· 没发布任务数据包的房（任务列显示「—」）在有任务筛选时会被排除
· 平台是「房主用的平台」，不是房间成员的平台；查不到时显示「—」
· 需要 Steam 客户端在线；系统需有 Edge WebView2 运行时（Win11 自带）
