# 更新日志

## V21（2026-11-21）

- **自动更新改用 GitHub Release**：不再依赖 A网，升级源为
  `https://github.com/QLongYan/HD2LobbyBrowser/releases/latest`。
- **启动自动检查版本**：每次启动在后台查一次最新版（不阻塞窗口）。
  - 有新版本 → 标题旁显示金色「有新版 V22」，「升级」按钮点亮
  - 已是最新 → 显示「已是最新版」，按钮置灰
  - 网络失败 → 显示「检查更新失败」，按钮仍可手动点击重试
- **升级失败提示**改为新文案（B站 / A网两个入口），两个链接均可点击。
- 下载顺序：自定义直链 → Release 资产 → `releases/latest/download` → 国内镜像
  （ghproxy.net / gh-proxy.com）；总耗时上限 150 秒，超时即失败。
- 修复：窗口版入口此前没有触发版本检查（V20 的「有新版本」提示实际不会出现）。

## V20（2026-11-21）

- 「房主」列改为常显（原来要勾「私服」才出现），表头仍可排序。
- 新增「保存预设」：保存全部筛选状态到 `preset.json`，下次启动自动套用并直接搜索。
- 新增「升级」按钮（当时走 A网，实测不可用，V21 改走 GitHub）。

## V19（2026-11-21）

- 新增「平台」列与 PC / PS / Xbox 筛选：平台来自 PlayFab 公开资料字段
  `testament_backing_platform`（0=PS / 1=Steam / 4=Xbox），用本机 Steam 票据只读查询。
- 跨平台房的房主名一并补上（覆盖率 0.3% → 约 80%）。

- 修复「勾 10 级难度，进游戏全是闪电战」。
